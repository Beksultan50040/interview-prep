# Behavioral

Senior interviews weigh ownership, influence, and judgement heavily.

## STAR format

- **Situation:** short context.
- **Task:** your responsibility or goal.
- **Action:** what you did and why. Use "I", not only "we".
- **Result:** measurable outcome and what you learned.

## Prepare 5 to 7 stories

Each story can answer several questions. Fill these in and keep them short.

| Theme | Story title | Result (numbers) |
|---|---|---|
| Technical leadership or a hard design decision | | |
| Production incident and what you changed afterwards | | |
| Disagreement with a teammate or stakeholder | | |
| Mentoring or raising team standards | | |
| Delivering under tight deadlines or scope trade-offs | | |
| A failure or mistake | | |
| Improving performance, cost, or reliability | | |

## Common questions

- Tell me about yourself (60 to 90 seconds: present, past, why this role).
- Why are you leaving and why this company?
- Describe a time you disagreed with a technical decision.
- How do you handle technical debt?
- How do you give and receive code review feedback?
- What would you do in your first 90 days?

## Questions to ask them

- How does the team make and record architecture decisions?
- What does on-call look like and how are incidents handled?
- How is success measured for this role in the first year?
- What is the biggest technical challenge in the next 6 months?

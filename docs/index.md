# Senior Java Interview Prep

One place for everything needed to prepare for a senior Java developer interview, so the next round starts here instead of from a blank page.

## How to use this site

1. Start with the [Roadmap](roadmap.md) and pick a timeline (1, 2 or 4 weeks).
2. Work through the topic sections. Each page has key concepts, common questions and "gotchas".
3. Practice with the [Question bank](question-bank.md).
4. After each interview, fill in an [Interview log](interview-log/index.md) entry. This is the step that keeps the site useful.

!!! tip "What senior means in interviews"
    Beyond knowing the API, expect to explain trade-offs, failure modes, performance reasoning, and past decisions you led. Always answer with: what, why, trade-offs, and an example from your own work.

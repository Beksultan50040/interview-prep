# Algorithms and coding

## Patterns to practice

- Two pointers, sliding window
- Hash map for counting and lookup
- Binary search (including on the answer)
- Stack and monotonic stack
- BFS and DFS, topological sort
- Heap and top-K
- Intervals, merging, sweeping
- Dynamic programming basics (1D, 2D, knapsack)
- Backtracking
- Union-Find

## Practice plan

- [ ] 2 to 3 problems per day for 2 weeks, mixed easy and medium
- [ ] Redo failed problems after 3 days
- [ ] Time-box each problem to 30 minutes, then study the solution
- [ ] Say your reasoning aloud, as in the interview

## During the interview

1. Restate the problem and ask about constraints and edge cases.
2. Start with a brute-force idea and state its complexity.
3. Improve it, explain the trade-off, then code.
4. Test with a small example and edge cases (empty, one element, duplicates, large input).

## Java-specific tips

- Know `Collections`, `Arrays`, `Comparator.comparing`, `PriorityQueue`, `ArrayDeque`, `StringBuilder`.
- Watch for integer overflow and `Integer` equality with `==`.

# Roadmap

Tick items as you go. Adjust the timeline to the interview date.

## Week 0: setup (1 to 2 hours)

- [ ] Read the job description and list the required technologies
- [ ] Mark the topics below as strong, medium or weak
- [ ] Prepare 5 STAR stories (see [Behavioral](behavioral.md))
- [ ] Update the CV with measurable results

## Week 1: Java foundations

- [ ] [JVM, memory and GC](java-core/jvm-memory-gc.md)
- [ ] [Concurrency](java-core/concurrency.md)
- [ ] [Collections internals](java-core/collections.md)
- [ ] [Modern Java 8 to 21](java-core/modern-java.md)
- [ ] 3 to 5 coding problems per day

## Week 2: frameworks and data

- [ ] [Spring and Spring Boot](spring/spring-boot.md)
- [ ] [Transactions, JPA, SQL](spring/data.md)
- [ ] [Testing](testing.md)
- [ ] Review slow queries, indexes, and the N+1 problem with a small demo project

## Week 3: architecture

- [ ] [Microservices and messaging](architecture/microservices.md)
- [ ] [System design](architecture/system-design.md)
- [ ] [Design principles and patterns](architecture/patterns.md)
- [ ] Practice 2 system design questions out loud

## Week 4: polish

- [ ] Mock interviews (peer or recorded)
- [ ] Review the [Question bank](question-bank.md) and weak spots
- [ ] Prepare questions to ask the interviewer
- [ ] Research the company, product and tech stack

## Shorter plans

=== "1 week"
    Focus on the weakest 3 topics from Week 0, 2 system design drills, 5 STAR stories, daily coding practice.

=== "2 weeks"
    Weeks 1 and 2 above in compressed form, plus 2 system design drills and the STAR stories.

## After the interview

- [ ] Add an entry to the [Interview log](interview-log/index.md) within 24 hours
- [ ] Add new questions to the [Question bank](question-bank.md)
- [ ] Sort links from the [Inbox](inbox.md)
